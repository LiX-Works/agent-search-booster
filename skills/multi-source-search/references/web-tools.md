# 网页、正文与代码资料

以下是**可选入口类型**，使用时以当前会话的工具名称、参数和权限为准。缺少某个服务可以换用其他来源，不把配置存在或登录成功等同于本次查询可用。

| 需求 | 可能使用的渠道 | 核验重点 |
|---|---|---|
| 发现普通网页 | 内置搜索；可选 Exa、Tavily 等 | 打开原页，核对时间与出处 |
| 补读正文 | 原始网页；必要时单页抓取或正文抽取 | 抽取可能遗漏表格、脚注或动态内容 |
| 查库和 SDK | 官方文档、原仓库；可选 Context7 | 核对版本、代码示例和原始链接 |
| 查仓库讨论 | GitHub 公开页面；确有需要时用已授权 CLI | 搜索结果、issue 评论和实际代码是不同证据 |

远程 MCP 由服务提供者处理请求；本地保存其连接配置，不代表服务在本机运行或额度无限。对来源缺失，可改查询范围或渠道，但不要无限重复同题、把 429 一律视作额度耗尽，或自行切到未经授权的按量计费路径。
