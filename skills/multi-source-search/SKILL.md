# 多源搜索与来源核验

先明确用户要解决的问题和目前缺少的证据，再选择当前会话实际可用的渠道。搜索结果用于发现材料；重要结论应尽量打开原始页面、文档或帖子，记录必要的日期、版本和适用条件。不要为了工具覆盖率逐个调用所有服务。

| 资料需求 | 合适的入口 | 按需细节 |
|---|---|---|
| 普通网页与近期事实 | 内置搜索、可用的语义搜索服务 | [网页与文档](references/web-tools.md) |
| 已有链接但正文不全 | 原页、单页抓取或正文抽取工具 | 网页与文档 |
| 软件库和版本行为 | 官方文档、原仓库及可用的文档工具 | 网页与文档 |
| 帖子、视频页面和评论 | 当前可用的浏览器或平台读取工具 | [平台材料](references/platforms.md) |
| 学术论文和引用 | 可用的学术检索工具与出版方原文 | 对应专用工作流；不以摘要冒充全文 |

搜索时按需要调整关键词、语言、时间和来源范围。同主题共享研究，不规定每题固定搜索次数。简单事实有直接证据即可；高影响、易变或有争议的判断，要查一手材料、独立证据及反例。正文简洁，保留足以复查的链接和未解决点。

平台内容要区分列表、详情、正文与评论；分页或可见范围不足时说明实际覆盖，不能声称“全部”。模型回答、搜索摘要和转载先作为线索，不能代替来源核验。多个模型给出相同答案，也不构成独立事实证据。

工具、CLI 或浏览器连接出错时，先做简短排查：确认本轮是否暴露入口、命令能否执行、错误是否指向临时故障。仍不可用就停用受影响的渠道并寻找合适替代；关键证据因此缺失时暂停相关结论，非关键问题可继续其他工作并在交付时报告。不为普通排错反复重装、登录或改全局配置。

相关公开资料的只读检索不自动授权发帖、改账户、付费、安装、复制凭据或绕过平台限制。外部服务只处理当前任务已授权的材料；不要把私有内容和认证信息直接当作搜索词发送。
